# Hangugo Words

Веб-приложение на Flask для запоминания корейских слов с помощью флеш-карточек,
тестирования и диктанта. Тёмная тема, адаптивная вёрстка.

## Возможности

- Загрузка списков слов из `.docx`, `.xlsx`, `.csv` (два столбца: корейское слово и перевод).
- Библиотека загруженных файлов, хранение слов в SQLite.
- Режимы работы со списком слов: **Запоминание** (карточки), **Тестирование**
  (выбор из 4 вариантов, направление KR→RU / RU→KR), **Диктант** (ввод текста).
- Прогресс-бар сессии и кнопка «Пропустить» (слово возвращается в конец очереди).
- Глобальный режим «Только ошибки»: собирает все слова, на которые когда-либо
  был дан неверный ответ, и слова, отмеченные звёздочкой как «сложные», —
  из всех файлов сразу. Также доступен локальный вариант «Повторить ошибки
  этого файла» на странице конкретного файла.

## Установка и запуск (локально)

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

```bash
python app.py
```

Приложение будет доступно на `http://127.0.0.1:5000`. База данных SQLite
и файлы сессии создаются автоматически в папке `instance/` при первом запуске.

## Запуск в production (например, на Render/Railway/VPS)

```bash
gunicorn wsgi:app
```

Переменные окружения (опционально):

- `SECRET_KEY` — секретный ключ Flask-сессии (обязательно задать для продакшена).
- `DATABASE_URL` — строка подключения к БД (по умолчанию SQLite в `instance/hangugo.db`).

## Структура проекта

```
app.py            — фабрика приложения, конфигурация, запуск
wsgi.py           — точка входа для gunicorn/production
models.py         — модели SQLAlchemy (File, Word, ErrorLog, HardWord)
parsers.py        — парсинг .csv/.xlsx/.docx
quiz.py           — логика тестов/диктанта, отметка ошибок и «сложных» слов
session_logic.py  — очередь слов текущей сессии (Flask session)
routes.py         — все маршруты приложения
templates/        — Jinja2-шаблоны (Bootstrap 5, тёмная тема)
static/           — CSS и JS
```
